# UI outline Foode + taste-skill (não Airbnb Rausch)

Primary e accent vêm do **logo oficial Foode** (`#F35050` / `#FFB800`); containers de conteúdo são **outline** (borda fina, sem fill, sem shadow, cantos arredondados). [DESIGN.md](../DESIGN.md) só empresta densidade/spacing/canvas-ink.

Na implementação de telas, carregar **`design-taste-frontend`** (`npx skills add https://github.com/Leonxlnx/taste-skill --skill design-taste-frontend`) para evitar slop e manter simplicidade.
