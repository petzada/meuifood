# Decisão: checklist de evidências e sequência BaaS Asaas

**Data:** jul/2026 · **Status:** decidido · **Sessão:** grilling BaaS #7  
**Depende de:** [47](47-tomadora-baas-ltda-apos-piloto.md)–[52](52-espera-sem-limite-ate-baas.md) · docs Asaas BaaS / avaliação / Res. 16/17

## Decisão

Playbook canônico de evidências e sequência:

| Fase | Ação |
| --- | --- |
| **Agora (piloto MEI)** | Contato informativo ([51](51-contato-informativo-asaas-piloto.md)); **não** criar 1ª subconta em produção no MEI; **não** pedir homologação ainda |
| **Perguntas ao gerente** | LTDA obrigatória p/ Tomadora? Playbook marca Asaas (Res. 16/17)? Docs sócios (selfie+RG/CNH)? Prazo típico? Taxa/contrato BaaS? |
| **Piloto validado** | Julgamento founder ([48](48-gatilho-piloto-validado-ltda.md)) → abrir **LTDA** |
| **LTDA aberta** | Conta Asaas na LTDA = Tomadora; pedir homologação formal + receber playbook |
| **Evidências de produto** | Marca Asaas em onboarding/comprovantes/contratos (conforme playbook); webhooks na criação de subconta; docs via `onboardingUrl` |
| **Durante homologação** | Zero novos lojistas ([52](52-espera-sem-limite-ate-baas.md)); **não** depender do teto 10 / R$ 2k / 60d para GTM |
| **BaaS liberado** | Migrar piloto → subconta ([50](50-migracao-piloto-para-baas.md)); novos nascem em `baas` via **UI onboarding no `admin`** ([54](54-implicacoes-minimas-modo-baas.md)); modelo único = subcontas |

## Limites do período de avaliação (lembrete)

- Máx. **10** subcontas de titulares diferentes  
- Máx. **R$ 2.000** em cobranças **por** subconta  
- **60 dias** corridos após a 1ª subconta  
- Foode **não** usa esse período como estratégia de escala ([52](52-espera-sem-limite-ate-baas.md))
