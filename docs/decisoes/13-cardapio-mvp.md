# Decisão: escopo do cardápio (MVP)

**Data:** jul/2026 · **Status:** decidido · **Sessão:** grilling #13

## Decisão

Cardápio MVP = **essencial + opcionais/complementos**.

| Capacidade | MVP |
| --- | --- |
| Categorias | Sim |
| Itens (nome, preço, foto, descrição) | Sim |
| Disponibilidade liga/desliga (item) | Sim |
| Horário / funcionamento da loja | Sim |
| Complementos configuráveis pelo comerciante | Sim |
| Adicionais com preço (configuráveis) | Sim |

## Fora do MVP

- Combos estruturados como produto à parte (pode modelar via complementos se necessário)
- Agendamento de pedido para data/hora futura
- Cardápio distinto por faixa (almoço vs jantar) como motor dedicado
- Estoque fino / fichas técnicas
